# League Mod CLI

> **Note:** This page is a placeholder. Detailed CLI documentation will be added as the tool matures.

The `league-mod` CLI provides command-line access to mod management functionality. It uses the same core libraries as LTK Manager but runs entirely in the terminal.

## Overview

The CLI is designed for:

- **Automation** — Scripting mod builds and installations
- **CI/CD** — Packaging mods in automated pipelines
- **Terminal users** — Managing mods without a GUI
